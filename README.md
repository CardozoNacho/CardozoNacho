## Professional experience

Since June 2025, I have worked as a junior software developer on SIGAP, a municipal management system in production. My work includes Java 8, JSP/Servlets, Hibernate/JPA, Apache Tomcat, PostgreSQL and SQL: maintenance, business validations, reports, query optimization and incident resolution.

I build complete features, from JSP views and JavaScript interactions to Java servlets and persistence. I work directly with users to understand requirements, analyze the domain and define solutions alongside another developer. I organize tasks in Jira, demonstrate changes and incorporate feedback.

I developed an **interactive public-lighting map** with OpenLayers, Java and PostgreSQL/PostGIS, using geographic information previously accessed through QGIS. It includes GeoJSON layers, viewport queries, search, spatial selection, individual and bulk editing, and integration with work-order forms. I also developed statistics on lighting assets, electricity consumption and invoice spending.

For **SIGAP Facturas AI**, I developed an invoice extraction workflow using Python and a local multimodal model, integrated with SIGAP's Java application. It has processed invoice batches; accuracy and time savings have not yet been quantified.

I also developed and deployed **SIGAP → RCC invoice submission automation** to production, using Python and Playwright integrated with Java and PostgreSQL. It validates invoice data, checks existing records to avoid duplicate submissions, and verifies portal records before updating each invoice's status in SIGAP. The implementation includes automated component tests, a Windows installer and local credential protection with Windows DPAPI. Usage and time savings have not yet been quantified.
