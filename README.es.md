## Experiencia profesional

Desde junio de 2025 trabajo como desarrollador de software junior en SIGAP, un sistema de gestión municipal en producción. Trabajo con Java 8, JSP/Servlets, Hibernate/JPA, Apache Tomcat, PostgreSQL y SQL: mantenimiento, validaciones de negocio, reportes, optimización de consultas y resolución de incidentes.

Desarrollo funcionalidades completas, desde vistas JSP e interacciones JavaScript hasta servlets Java y persistencia. Relevo necesidades directamente con usuarios, analizo el dominio y defino soluciones junto con otra desarrolladora. Organizo tareas en Jira, muestro los cambios e incorporo sus comentarios.

Desarrollé un **mapa interactivo de alumbrado público** con OpenLayers, Java y PostgreSQL/PostGIS, aprovechando la información geográfica previamente utilizada en QGIS. Incluye capas GeoJSON, consultas por área visible, búsquedas, selección espacial, edición individual y masiva y conexión con la carga de órdenes. También desarrollé estadísticas de luminarias, consumo eléctrico y gasto en facturas.

En **SIGAP Facturas AI** desarrollé un flujo de extracción de datos de facturas con Python y un modelo multimodal local, integrado con la aplicación Java de SIGAP. Ya procesó lotes de facturas; todavía no se cuantificaron precisión ni ahorro de tiempo.

También desarrollé y desplegué en producción la **automatización de carga de facturas SIGAP → RCC**, con Python y Playwright integrados con Java y PostgreSQL. Valida los datos, consulta registros existentes para evitar altas duplicadas y comprueba los registros del portal antes de actualizar el estado de cada factura en SIGAP. Incluye pruebas automatizadas de componentes, instalador para Windows y protección local de credenciales con Windows DPAPI. Todavía no se cuantificaron su uso ni el ahorro de tiempo.
